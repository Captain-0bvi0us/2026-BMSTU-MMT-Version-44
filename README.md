# ТММ ДЗ 26 — Вариант 44 (Android Gaze Fixations)

Полная реализация варианта 44:
**Обнаружение, отслеживание и визуализация фиксаций взгляда глаз человека на точках экрана смартфона. Вычисление координат фиксации в системе координат экрана и их визуализация.**

## Возможности

- Поток с фронтальной камеры через **CameraX** (`Preview` + `ImageAnalysis`).
- Детекция лица и 478 face-landmarks через **MediaPipe Tasks Vision FaceLandmarker** (с iris-моделью).
- Извлечение направления взгляда из ARKit-style blendshapes (`eyeLookIn/Out/Up/Down × Left/Right`).
- **Полноценная 9-точечная калибровка** с полиномиальной регрессией 2-го порядка (МНК):
  - модель: `screen = a0 + a1·gx + a2·gy + a3·gx·gy + a4·gx² + a5·gy²`,
  - регуляризация Тихонова,
  - решение методом Гаусса с частичным выбором главного элемента,
  - коэффициенты сохраняются в SharedPreferences,
  - оценка средней ошибки калибровки (px).
- **Детектор фиксаций по алгоритму I-DT** (Dispersion-Threshold) с настраиваемыми порогами разброса и dwell-time.
- Визуализация в режиме «Видео»:
  - рамка лица, точки радужек и носа,
  - текущая точка взгляда (crosshair) в координатах экрана,
  - траектория последних сэмплов взгляда,
  - точки фиксаций с номером и размером, пропорциональным длительности,
  - линии саккад между фиксациями,
  - 4×4 опциональная сетка экрана.
- Режим **Тепловая карта (Heatmap)**: полноэкранная радиальная гладкая визуализация фиксаций.
- Полноэкранный оверлей **калибровки**: пульсирующая жёлто-красная точка по 9 позициям.
- Информационная панель: координаты взгляда (px, normalized), сырое направление, углы Эйлера головы.
- Панель статистики: число фиксаций, средняя/общая длительность, статус фиксации и калибровки.
- **Экспорт CSV** с фиксациями через `FileProvider` (Intent.ACTION_SEND).
- Сброс калибровки, очистка фиксаций, переключатели лица/сетки/фиксаций.

## Запуск

1. Откройте папку `2026-BMSTU-MMT-Version-44` в Android Studio (Iguana / Koala +).
2. Дождитесь Gradle Sync.
3. JDK 17 (Gradle JDK) — `compileSdk = 35`, `minSdk = 24`.
4. Подключите телефон с фронтальной камерой (рекомендуется реальное устройство;
   на эмуляторе включите Virtual Scene/Webcam в настройках камеры AVD).
5. Запустите модуль `app`, разрешите доступ к камере.

## Алгоритм работы (вкратце)

1. CameraX отдаёт кадры 640×480 RGBA → `GazeAnalyzer`.
2. MediaPipe FaceLandmarker (LIVE_STREAM, model `face_landmarker.task`)
   возвращает 478 точек + iris (468/473) + blendshapes + facial transformation matrix.
3. Из blendshapes собирается направление взгляда в нормированных координатах `(gx, gy) ∈ [-1, 1]`.
4. `GazeCalibrator` отображает `(gx, gy)` → `(screen_x, screen_y)` в пикселях экрана:
   - **до калибровки** — линейное `gx → 0.5 + 0.5·gx`,
   - **после калибровки** — полиномиальная регрессия по 6 коэффициентам, найденная из 9 пар сэмплов.
5. Экспоненциальное сглаживание (`α = 0.22`) гасит дрожание зрачка.
6. `FixationTracker` (I-DT) удерживает буфер последних 4·dwellMs и измеряет максимальное удаление от центроиды;
   при `dispersion ≤ 60 px` и `dwellTime ≥ 250 ms` — открывает фиксацию, накапливает её длительность и сэмплы.
7. Все фиксации рисуются в координатах экрана и опционально визуализируются как тепловая карта.

## CSV экспорта

Колонки: `index, start_time_ms, duration_ms, screen_x_px, screen_y_px, norm_x, norm_y, samples`.

## Примечание

Эта реализация полностью алгоритмическая (без нейросетевого регрессора).
Для метрологической точности всё равно нужна индивидуальная калибровка
и стабильное расстояние от камеры до глаз. Модель `face_landmarker.task`
лежит в `app/src/main/assets/`.
