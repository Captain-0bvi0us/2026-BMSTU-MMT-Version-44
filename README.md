# ТММ ДЗ 26 — Вариант 44 (Android)

Проект реализует вариант 44: обнаружение и отслеживание фиксаций взгляда на точках экрана смартфона, вычисление координат фиксации и их визуализация в реальном времени.

## Что реализовано

- Поток с фронтальной камеры через CameraX (`Preview` + `ImageAnalysis`).
- Детекция лица и контуров глаз (`ML Kit Face Detection`).
- Оценка направления взгляда в координатах кадра и преобразование в координаты экрана.
- Трекинг фиксаций (dwell-time + радиус устойчивости).
- Отрисовка:
  - рамка лица,
  - текущая точка взгляда (crosshair),
  - накопленные точки фиксации.
- Текстовый вывод координат `X/Y` (нормированные и пиксельные) + число фиксаций.

## Запуск

1. Откройте папку `2026-BMSTU-MMT-Version-44` в Android Studio.
2. Дождитесь Gradle Sync.
3. Убедитесь, что выбран JDK 17 или JBR 21 (Gradle JDK).
4. Запустите эмулятор (например Pixel 6, API 34) или подключите телефон.
5. Нажмите Run для модуля `app`.
6. Разрешите доступ к камере.

## Структура ключевых файлов

- `app/src/main/java/com/example/variant44gaze/MainActivity.kt` — запуск камеры, обновление UI.
- `app/src/main/java/com/example/variant44gaze/GazeAnalyzer.kt` — кадр → ML Kit → точка взгляда.
- `app/src/main/java/com/example/variant44gaze/FixationTracker.kt` — детекция фиксаций.
- `app/src/main/java/com/example/variant44gaze/OverlayView.kt` — визуализация точки и фиксаций.
- `app/src/main/java/com/example/variant44gaze/PoseMath.kt` — 3D-повороты вектора.

## Примечание

Это учебная реализация для демонстрации варианта 44. Для точной eye-tracking системы нужна калибровка камеры и пользователя.
